# Russian GPT: обучение с нуля и LoRA

Учебный проект из двух экспериментов: небольшая GPT-подобная модель для русской прозы и LoRA-адаптер для исправления текста на основе Qwen3-1.7B-Base.

Источники: [Taiga Proza](https://huggingface.co/datasets/cointegrated/taiga_stripped_proza), [spell-correction-ru](https://huggingface.co/datasets/melsmm/spell-correction-ru), [Qwen3-1.7B-Base](https://huggingface.co/Qwen/Qwen3-1.7B-Base).

## GPT с нуля

Тексты прозы очищены, разбиты на train/val/test и закодированы BPE-токенайзером на 16 000 токенов. Модель реализована на PyTorch в `model.py`: causal self-attention, Transformer-блоки, позиционные эмбеддинги. Основная конфигурация: 48,1 млн параметров, контекст 256 токенов, 10 блоков, ширина 512, 8 голов.

| Параметров | Шагов | Val loss |
|---:|---:|---:|
| 8,0 млн | 199 092 | 4,545 |
| 13,0 млн | 450 000 | 4,092 |
| 26,6 млн | 250 000 | 4,033 |
| 48,1 млн | 300 000 | 3,764 |

Это история экспериментов, а не контролируемое сравнение размеров: число шагов и режимы обучения различались. Для генерации связного текста качества последней модели всё ещё недостаточно.

Запуск основного обучения после подготовки JSONL и токенайзера:

```powershell
python train_small_gpt.py --data-dir "ПУТЬ_К_ПОДГОТОВЛЕННЫМ_ДАННЫМ"
```

Скрипт сохраняет контрольные точки в `runs/scratch/`. Для продолжения служит параметр `--resume` с путём к контрольной точке. Локальные пути к данным передаются через аргументы и не входят в репозиторий.

## LoRA для исправления текста

На Qwen3-1.7B-Base обучен LoRA-адаптер для `q_proj` и `v_proj`: 1,61 млн обучаемых параметров при `r=8`. Обучение шло на 23 390 парах; 1 253 пары выделены для валидации. После 9 500 порций val loss составил 0,0444. На 100 примерах из той же выборки точное совпадение с эталоном выросло с 44/100 у исходной Qwen до 76/100 с адаптером.

На другом источнике улучшение не подтвердилось. Поэтому результат относится к этой валидационной выборке и не означает универсального улучшения корректора.

```powershell
python lora/train_lora.py --model-dir "ПУТЬ_К_QWEN3-1.7B-BASE" --data-dir "ПУТЬ_К_ДАННЫМ_ДЛЯ_ИСПРАВЛЕНИЯ"
```

Скрипт сохраняет адаптеры в `runs/lora/`. Базовая модель, наборы данных и контрольные точки в репозиторий не включены.
